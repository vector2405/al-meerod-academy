AL-MEEROD ACADEMY WEBSITE — QUICK START

Files:
- index.html: page content
- style.css: design and responsive layout
- script.js: mobile menu, scroll animations, navigation highlight, enquiry form demo

How to preview:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

Before publishing:
1. Replace the AM placeholder mark with the school's corrected logo.
2. Add real school photos in place of the photo placeholders.
3. Confirm the official phone/WhatsApp number, school opening date, classes currently offered, admissions details and fees.
4. Confirm the official school name spelling. This draft uses “Al-Meerod Academy”.
5. Review all text with school management. Do not publish unconfirmed claims.
6. For WhatsApp enquiries, update script.js with the school's confirmed WhatsApp number and implement the form's submit handler.
7. Consider adding a privacy notice if you collect parent/student information.

This is a static website draft; the enquiry form does not currently send or store submissions.
